# The Forge Wars

2026-09-11

I'm currently experiencing *forge fatigue*. Most of my projects are hosted and mirrored across Codeberg, Sourcehut, and GitHub[^1]. My main issue has been trying to determine the best "home base" or deciding which one to be the *real* git forge. 

This is proving quite difficult. 

The problem is that some developers will shame you for using GitHub, some will disagree with Codeberg's ToS, and others will complain about Sourcehut's email-based workflow. It's impossible to make every user happy. Such is life.

Luckily we don't have to force ourselves into one, single silo. This is the beauty of `git`, after all.

[^1]: I've tried self-hosting my projects previously, but that proves to be even more of a headache for those wishing to contribute.
